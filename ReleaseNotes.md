# Release Notes

Human-readable record of shipped releases for Brainstormer. **Update this file on every release** with the version, date, and a summary of features and bug fixes delivered.

- For detailed, per-commit history see `CHANGELOG.md`.
- Per-app/per-release artefacts generated by the product live in `docs/release-notes/`.

## How to add an entry

1. Add a new section at the top: `## vX.Y.Z — YYYY-MM-DD`.
2. List **Features** and **Bug fixes** (omit a subsection if empty). Note breaking changes clearly.
3. Keep entries factual and user-facing; link issues/IDs where helpful.

## v0.89.0 — 2026-11-16

### Features
- **Flutter/legacy web cutover:** legacy Jinja web routes are now retired by default (`LEGACY_WEB_ENABLED=False`, returning 410). Set `LEGACY_WEB_ENABLED=True` to temporarily re-enable them while completing migration; Jinja template removal is tracked as follow-up work (RM-013).

### Documentation
- Roadmap updated: RM-010 completed (cutover flip) and replaced by RM-013 for template removal after monitoring.

## v0.88.2 — 2026-11-16

### Features
- Renamed the user-facing "PRD" to **Brief** across the product: lifecycle tab, action labels, gate and confirmation messages, release pipeline labels, and prompt templates. Existing documents and APIs continue to work (internal identifiers unchanged).

### Bug fixes
- Corrected a UI test selector to match the "Run pipeline" button label.

### Documentation
- Roadmap reset to outstanding-only work with unique IDs and phased releases; added `ReleaseNotes.md`. Removed RM-011 (Tests tab) as already shipped in earlier releases (e.g. v0.77.0).

## v0.88.1 — 2026-11-15

### Features
- Moved the **Analysis** tab beside **Idea** (ahead of Brief) so existing reads stay together on the left of forward steps.

## v0.88.0 — 2026-11-15

### Features
- Idea detail tabs follow the lifecycle with a fixed order (**Brief, Design, Build, Tests**) so the next required step is not buried by analysis results.
- Consolidated exploratory results (competitors, feasibility, forces, PESTEL, VRIO, 3Cs, market sizing, canvas, hypothesis test, GTM) into a single **Analysis** tab with chips (newest first), date, and Markdown copy/export.
- Added an action `category` (`action` or `analysis`) so new actions group automatically without UI changes.

### Bug fixes
- Removed the redundant "Prompt" tab from the strip (prompt link remains in the modal meta row).
