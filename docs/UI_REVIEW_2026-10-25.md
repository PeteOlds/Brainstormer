## Bugs found and fixed during the review

1. **`/home` threw `ReferenceError: messages is not defined` and
   `canMessageAnyone is not defined`** on every load (x4). Both are written
   by `init()` but were missing from the `homeApp()` state object, so the
   first render evaluated undefined properties. Added them to state.
2. **`/ideas` threw `TypeError: Cannot read properties of undefined
   (reading 'cloneNode')` once per card (10×).** The 3-dot menu used
   `<button x-if="...">`; `x-if` must sit on a `<template>`. Alpine then
   tried to clone a non-existent `content` fragment. Wrapped the button in
   `<template x-if>`.
3. **Horizontal page scroll at 768–818 px.** The top nav links plus the user
   block overflowed by 13 px at 800 px, clipping the Logout button. Tightened
   the link gap (`space-x-4` → `space-x-1`) and link padding; verified
   `scrollWidth == clientWidth` at 390/800/1024/1440.
4. **Archive was a raw terminal status in every dropdown.** Replaced with
   plain-language actions (see `docs/Design.md` §6b): “Archive this idea” /
   a bulk “Archive selected” button, and confirmation
   dialogs. `ARCHIVE` now appears only in the status *filter*.
5. **Action menu could run past the bottom of the viewport.** Added
   `max-h-[70vh] overflow-y-auto`.
6. **Backup file downloads 500ed (`FileNotFoundError`).** `BACKUP_DIR` is
   relative (`./backups`); `os.listdir()` resolved it from the process CWD
   while `send_file()` resolves relative paths against `app.root_path`, so
   the list worked but the download looked in `/app/app/backups`. Made the
   path absolute.
7. **Backup uploads arrived empty (`Choose a backup file`).** `authFetch()`
   forced `Content-Type: application/json` on every request with a body,
   which strips the multipart boundary. It now leaves FormData alone.
8. **Backup page header duplicated its explanation** (both the site-admin and
   instance-admin sentences were in one span). Reworded.

## Verified interactions (not just rendering)

- Card 3-dot menu: View Details, status select without Archive, Discard,
  Archive/Restore, action list.
- Detail modal: opens, shows status, has Edit content and Archive/Restore
  buttons; confirming Archive shows the plain-language dialog; cancelling
  leaves the idea at SPARK.
- Bulk bar: “Archive selected” opens the archive confirmation.
- `/admin/backup`: site panel, file list with Download/Restore, automation
  toggle, instance rows; clicking Restore on a stored file fetches and
  verifies it (23-table manifest shown), the confirm input is required, and
  “Restore now” stays disabled until `RESTORE` is typed.
- Responsive: no horizontal overflow at 390, 800, 1024, 1440 px on
  `/ideas`, `/admin/backup`, `/home`.
